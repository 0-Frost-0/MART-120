	Graphical user interfaces and command-line interfaces are types of interfaces that allow users to interact with software. Graphical user interfaces or GUIs use buttons, dropdowns, sliders, and icons. GUIs are more user friendly and can make using programs significantly easier. Command-line interfaces or CLIs use typed commands. CLIs take less system resources to run, are able to store a history, and are better at large scale operations. Some examples of GUIs are File Explorer and most touchscreens and mobile devices. A few examples of CLIs are Windows PowerShell and Unix. Overall GUIs are more popular than CLIs.
